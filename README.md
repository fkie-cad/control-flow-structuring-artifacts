# Control-Flow Structuring

This is the artifact repository to the paper `SoK: No Goto, No Cry? The Fairy Tale of Flawless Control-Flow Structuring`.

It contains all samples that were used to generate the examples considered in Section 4 of the paper.
Here, we have not only included the unmodified samples for the decompiliers used for each figure, but also the decompiler outputs for all decompilers considered in the paper.
The results are contained in the folder [examples_paper](examples_paper).

Furthermore, this repository contains all scripts used for our evaluation.
This includes the script for generating the dataset, the decompilation of all functions, and the computation of the metrics discussed in the paper.
The scripts are contained in the folder [evaluation](evaluation).
